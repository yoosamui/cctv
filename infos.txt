✅ 4. Add a health check (auto-restart if camera fails)

Create a watchdog script:

nano /home/pi/cctv/check_camera.sh
#!/bin/bash

if ! nc -z 192.168.1.82 554; then
    echo "Camera down, restarting service..."
    systemctl restart cctv-video-recorder@Center.service
fi

Make executable:

chmod +x /home/pi/cctv/check_camera.sh
